# Runking 真人写作风格（非 AI 语料）

> 适用：为 runking 代写 / 生成博客文章时加载。语料 = 博客内 92 篇非 AI 文章（重点取 `thoughts/` 下的随笔、哲学、思维碎片；排除 3 篇 AI 主题文，如《DNA、人、AI》《生成型代理》《从取代个人到重塑团队》）。
> 目的：让生成内容读起来像他本人写的，而不是像 AI 生成的。

## When to use
- 要替 runking 写一篇新博文（任何主题，包括 AI 主题，但语气要像他）。
- 要扩写 / 润色他给的提纲、碎片想法。
- 不确定某段话「像不像他」时，回来看下面的 Anti-patterns。

## Voice Profile（他本人的真实语气）

1. **开门见山，论断先行。** 第一句直接抛出核心观点，不铺垫、不「引言」、不「在……的今天」。
   - 范例：「成功的根本性原因是做到别人做不到的事情。」
   - 范例：「美是生物本能+大脑修饰的产物。」
2. **断言式、笃定。** 把个人观察当成既定事实陈述，少犹豫、少「可能」「也许」。允许不完整（他常留半句待续）。
   - 范例：「互联网或者说信息传播的提速，最大的恶是杀死了普通人」(句末即止)
3. **系统 / 分层 / 角色思维。** 喜欢把事物拆成层级、链条、角色来建模。
   - 范例：「角色：DNA-个人（大脑）-家庭-家族-地方-国家-人类。」
   - 范例：「需求层次理论的问题是：把需求的角色只是限定在了 DNA、个人这两个角色上。」
4. **极简箴言体。** 多数随笔是 1–5 句，一两句讲清一个洞见；宁可短，不要水。
5. **朴素直白的中文。** 词汇简单、短句、多用逗号做意合；不堆砌成语、不抒情、不排比装饰。
6. **因果链推进。** 用「X 造成 Y，Y 又造成 Z」把论点串起来，而不是列干条。
   - 范例：「人的天性是在资源富裕时，积攒资源。这个会造成紧缩。股市等一系列投资行为，诱使人们将钱花出去，避免了通货紧缩。这个是现在世界的经济模型。」

## Exemplars（真实原文，锚定语气）

- 「成功的根本性原因是做到别人做不到的事情。」 ——《成功的根本性原因》
- 「美是生物本能+大脑修饰的产物。人美：代表着个体生存的可能性，和后代可能延续的特性。景美：对自身安全、未来资源的影响。」 ——《关于美的思考》
- 「人的天性是在资源富裕时，积攒资源。这个会造成紧缩。股市等一系列投资行为，诱使人们将钱花出去，避免了通货紧缩。这个是现在世界的经济模型。」 ——《人类天性与经济循环》
- 「角色：DNA-个人（大脑）-家庭-家族-地方-国家-人类。需求层次理论的问题是：把需求的角色只是限定在了 DNA、个人这两个角色上。」 ——《角色、人性与本能》
- 「互联网或者说信息传播的提速，最大的恶是杀死了普通人」 ——《互联网的恶》

## Anti-patterns（AI 套话，一律避免）

- ❌ 开头「在当今世界 / 随着……的发展 / 近年来」。直接给观点。
- ❌ 段落里塞「值得注意的是 / 毋庸置疑 / 总而言之 / 综上所述」。
- ❌ 强行「三大维度 / 五个要点 / 首先…其次…最后」的模板化结构（除非他原文就用了编号分层）。
- ❌ 鸡汤式结尾（「希望对你有所启发」「让我们一起……」）。
- ❌ 过度客套、过度解释、重复同一个意思换说法。
- ❌ 长难句堆术语；用短句和逗号意合代替。

## How to apply（生成时的步骤）

1. **先抓一个锋利的核心论断**，作为第一句。
2. 用 1–3 句支撑（因果链 / 分层 / 角色拆分），不要铺陈。
3. 能短则短；宁可是 3 句箴言，也不要凑成 800 字八股。
4. 自查：删掉所有「在……的今天 / 值得注意的是 / 总而言之」类词；把任何「可能 / 也许」换成笃定陈述（除非真不确定）。
5. 若主题是长篇论述（如他《从取代个人到重塑团队》那种带小标题的结构文），保留清晰分层与 **加粗关键词**，但语气仍按上面 Voice Profile 走——断言、直接、不客套。
6. 发布走《blog-publishing-runbook.md》的流程（注意：本机别用 `hexo deploy`，走手动 git 部署）。

## Notes
- 此风格仅从「非 AI 文章」提炼；若代写 AI 主题，语气仍套这份 Profile，只是内容主题不同。
- 语料会随博客增长而变；如发现他近期语气明显变化，回来更新本 skill 的 Exemplars。
